4) PIPELINE DIARIO (implementado)
FETCH → NORMALIZE → DEDUP → CAPS → EVALUATE → DIGEST → NTFY → PERSIST
  • Cron: 0 9 * * * (09:00 UTC = 06:00 Argentina). GitHub puede
    atrasarlo ~15 min en horas pico.
  • Botón manual: Actions → daily-ingest → Run workflow.
  • FETCH: cada fuente con try propio — una caída NO frena la
    corrida. HTTP con reintentos y backoff exponencial.
  • NORMALIZE: esquema único + id estable (doi:... si hay DOI,
    si no sha256 del título normalizado).
  • DEDUP: id exacto + fuzzy (rapidfuzz >92) contra state/seen.json
    Y dentro de la misma corrida (dos fuentes, misma noticia).
  • CAPS: round-robin entre fuentes — ninguna acapara el lote.
  • EVALUATE: agente en chunks de 60 ítems, pausa 2s entre chunks.
    Si un chunk falla, esos ítems quedan fuera de ESTA corrida;
    si NO hay veredictos, seen.json NO se guarda → el lote completo
    se reintenta solo al día siguiente (nada se pierde).
  • DIGEST: reports/AAAA-MM-DD.md, agrupado por rubro.
  • NTFY: solo si hay ítems sobre el umbral. Top 10 (~4KB).
  • PERSIST: seen.json + reporte commiteados ("radar: corrida
    AAAA-MM-DD") — solo si hubo cambios.

5) VOLUMEN Y VÁLVULAS (todo en config/sources.yaml)
  caps.per_source: 50  ·  caps.total: 300  ·  threshold: 70/100
  openalex: days_back 2 · per_page 100 · max_pages 2
  arxiv: max_results 100
  notify: top_n 10 · max_bytes 4096
El agente NO resume todo: SELECCIONA lo mejor del día. Más
cobertura = subir caps/days_back. Menos ruido = subir threshold.
Nunca más corridas.

6) AGENTE EVALUADOR (implementado)
  • Primario: GitHub Models — openai/gpt-4o-mini — autenticado con
    el GITHUB_TOKEN del workflow (permiso models: read) → $0.
  • Fallback: Groq llama-3.3-70b-versatile — SOLO si existe el
    secret GROQ_API_KEY (opcional, hoy no creado).
  • Salida SIEMPRE en español: score 0-100 + rubro + región +
    resumen_es por ítem. JSON tolerante a fences ```; ítems sin
    veredicto se descartan de la corrida.
  • Rubros: investigacion | preprint | descubrimiento | patente |
    salud | tech | financiamiento | otro
  • Regiones: America Latina | Norteamerica | Europa | Asia |
    Africa | Oceania | Global

9) OPERACIÓN (chuleta)
  • Correr manual: Actions → daily-ingest → Run workflow → Run.
  • Leer el paso "Correr radar" en este orden:
      fetch total: N ítems → dedup: X nuevos / Y ya vistos →
      caps: A → B ítems → agente: chunk i/j → reporte escrito →
      ntfy: enviado
  • Agregar fuente RSS: 1 línea en sources.yaml (name, url, lang).
    Feed caído = warning en el log, la corrida sigue.
  • Ajustar: threshold ↑ (menos ruido) · caps.total ↑ (más
    cobertura) · openalex.days_back ↑ (más ventana).
  • Síntomas comunes:
      openalex: 0 ítems ....... revisar polite_email (placeholder?)
      rss: falló (404) ........ URL muerta → reemplazar en yaml
      agente sin veredictos ... seen no se guarda, reintenta solo
      ntfy: falló, resto OK ... revisar secret NTFY_TOPIC
      sin push, corrida verde . normal: nada superó el umbral
